# Password Strength Analyzer & Security Suggestion Tool

## Overview

A privacy-focused defensive cybersecurity application designed to evaluate password strength, identify predictable patterns, detect common-password weaknesses, and provide actionable security recommendations.

## Project Objectives

* Analyze password length and character diversity.
* Detect common passwords and predictable patterns.
* Estimate theoretical password entropy.
* Generate personalized security recommendations.
* Generate secure passwords using Python's cryptographically secure random module.
* Provide privacy-conscious password security education.
* Display aggregate analytics without storing submitted passwords.

## Technology Stack

* Python
* Flask
* HTML
* CSS
* JavaScript
* SQLite
* Chart.js
* Pytest

## Privacy and Security

* Submitted passwords are processed transiently.
* Plaintext passwords are never stored in the database.
* Passwords are never written to application logs.
* Passwords are not transmitted to external services by default.
* Synthetic passwords are used for testing and demonstrations.
